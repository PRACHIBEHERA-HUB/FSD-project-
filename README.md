 Online Learning Management System (LMS)

A full-stack MERN-based Learning Management System designed to provide a seamless online education experience for Admins, Faculty, and Students. This platform enables secure authentication, course management, study material sharing, assignment submission, and progress tracking through role-based dashboards.

 Features

-  JWT-based Authentication & Authorization
-  Role-Based Access (Admin, Faculty, Student)
-  Course Creation & Management
-  Study Material & Video Lecture Uploads
-  Assignment Submission & Grading
-  Student Progress Tracking
-  Course Search & Enrollment
-  Responsive User Interface
-  RESTful API Integration

 Tech Stack

- Frontend: React.js, React Router, Context API
- Backend: Node.js, Express.js
- Database: MongoDB (Mongoose)
- Authentication: JWT
- File Uploads: Multer

 Project Objective

The goal of this project is to simplify online education by bringing course management, learning resources, assignments, and progress tracking into one secure and user-friendly platform.
